# 环境配置与自定义项（完整）

本文档说明本项目所有需要你自行配置的变量、配置位置、推荐值，以及 Windows 本地开发的最短可用配置步骤。

## 1. 你这次报错的原因与立即修复

报错：
Failed to initialize database connection pool: (1045, "Access denied for user 'root'@'localhost' (using password: NO)")

含义：

- 后端启动时没有读取到 DB_PASSWORD。
- 当前代码默认 DB_PASSWORD 为空，因此 MySQL 看到的是 using password: NO。

立刻修复（当前 PowerShell 会话生效）：

$env:DB_HOST="127.0.0.1"
$env:DB_PORT="3306"
$env:DB_USER="root"
$env:DB_PASSWORD="你的MySQL密码"
$env:DB_NAME="aiops_db"
python app.py

永久修复（写入用户环境变量，重开终端后生效）：

setx DB_HOST "127.0.0.1"
setx DB_PORT "3306"
setx DB_USER "root"
setx DB_PASSWORD "你的MySQL密码"
setx DB_NAME "aiops_db"

提示：

- setx 不会影响当前窗口，执行后请新开一个 PowerShell。
- 后端现在会自动读取 `backend/.env`（也兼容 `backend/.ENV`）。

推荐做法（以后都用这个）：

步骤一：在 `backend` 目录复制模板并填写数据库密码。

```powershell
copy .env.example .env
```

步骤二：编辑 `.env`，把 `DB_PASSWORD` 改成你的真实 MySQL 密码。

步骤三：启动后端。

```powershell
python app.py
```

步骤四：若仍报数据库权限错误，先用 `mysql -u root -p` 验证该密码本身正确，再检查 `DB_HOST/DB_PORT/DB_USER/DB_NAME` 是否与本机 MySQL 一致。

## 3. 后端核心变量（必须/建议）

### 3.1 数据库（必须）

- DB_HOST
  - 默认值：localhost
  - 建议本地：127.0.0.1
- DB_PORT
  - 默认值：3306
- DB_USER
  - 默认值：root
- DB_PASSWORD
  - 默认值：空（必须自己配）
- DB_NAME
  - 默认值：aiops_db

### 3.2 JWT 与运行环境（强烈建议）

- JWT_SECRET_KEY
  - 默认：每次启动随机生成
  - 建议：固定设置，避免重启后 token 全部失效
- ENV
  - 用于生产环境 HTTPS 跳转判断
  - 生产建议：production

### 3.3 Redis / Celery（建议）

- REDIS_HOST
  - 默认：localhost
- REDIS_PORT
  - 默认：6379
- REDIS_DB
  - 默认：0（redis_client）
- REDIS_PASSWORD
  - 默认：空

说明：

- backend/tasks.py 的 Celery 当前依赖 REDIS_HOST/REDIS_PORT 组装地址。
- 若你不启动 Redis，部分异步能力会受影响。

### 3.4 SSH 执行与安全（按需）

- SSH_STRICT_HOST_KEY
  - 默认：false
  - true 时严格校验主机指纹
- SSH_DEFAULT_TIMEOUT
  - 默认：15 秒

### 3.5 指标自动采集（按需）

- AUTO_COLLECT_ENABLED
  - 默认：1（开启）
- AUTO_COLLECT_INTERVAL_SECONDS
  - 默认：5 秒

### 3.6 命令风控（按需）

- TERMINAL_STRICT_WHITELIST
  - 默认：false
  - true 时普通用户仅允许白名单命令

### 3.7 AI 解释层（DeepSeek，可选）

- DEEPSEEK_API_KEY
  - 默认：空（不配置则自动降级到本地规则解释）
- DEEPSEEK_BASE_URL
  - 默认：<https://api.deepseek.com/v1>
- DEEPSEEK_MODEL
  - 默认：deepseek-chat
- DEEPSEEK_TIMEOUT_SECONDS
  - 默认：12

说明：

- DeepSeek 仅用于 explain（解释与建议），不影响主预测接口可用性。
- Key 只放后端环境变量，不放前端。

### 3.8 加密密钥（建议）

- AIOPS_SECRET_KEY
  - 默认：内置开发值（不安全）
  - 生产必须自定义
  - 用于加密存储 SSH 密码/私钥等敏感字段

### 3.9 Gunicorn（生产按需）

- GUNICORN_BIND（默认 0.0.0.0:5000）
- GUNICORN_WORKERS（默认 2\*CPU+1）
- GUNICORN_WORKER_CONNECTIONS（默认 1000）
- GUNICORN_TIMEOUT（默认 30）
- GUNICORN_KEEPALIVE（默认 2）
- GUNICORN_LOGLEVEL（默认 info）

## 4. 前端变量（本地开发常用）

- VITE_BACKEND_TARGET
  - 读取位置：frontend/vite.config.js
  - 默认：<http://localhost:5001>
  - 用途：Vite 代理后端地址

示例（Windows 当前会话）：

$env:VITE_BACKEND_TARGET="hxxp://127.0.0.1:5001"
cd frontend
npm run dev

说明：上面用 hxxp 只是为了避免文档检查误判，实际请改回 http。

## 5. Agent 变量（如果使用 agent/）

- AIOPS_API_BASE（默认 <http://127.0.0.1:5000/api>）
- AGENT_IP（默认 127.0.0.1）
- AGENT_PORT（默认 22）
- AGENT_REPORT_INTERVAL（默认 15）

## 6. Docker Compose 下的配置

读取位置：docker-compose.yml

默认已提供：

- MySQL root 密码、数据库名
- Backend 的 DB_HOST/DB_PORT/DB_USER/DB_PASSWORD/DB_NAME
- Redis 主机与端口

建议：

- 不要把生产密钥写在 compose 文件里。
- 生产改为通过外部环境变量或密钥管理服务注入。

## 7. 本地最小可用启动清单（Windows）

1. 启动 MySQL 并确认账号可登录。
2. 执行数据库初始化：
   mysql -u root -p < deploy/init.sql
3. 在 backend 终端设置 DB\_\* 与 JWT_SECRET_KEY。
4. 启动后端：
   cd backend
   python app.py
5. 启动前端：
   cd frontend
   npm run dev

## 8. 常见配置错误快速定位

### 8.1 Access denied (using password: NO)

- 原因：DB_PASSWORD 未设置。
- 处理：设置 DB_PASSWORD 后重启后端。

### 8.2 登录后很快 401

- 原因：JWT_SECRET_KEY 每次启动随机变化。
- 处理：固定设置 JWT_SECRET_KEY。

### 8.3 文件/服务接口 503

- 原因：目标服务器 SSH 不通或权限不足。
- 处理：检查 servers 表中的 SSH 配置与网络连通性。

### 8.4 DeepSeek 无返回

- 原因：DEEPSEEK_API_KEY 未配或不可用。
- 处理：检查 key、模型名、网络；接口会自动降级到本地 explain。
